## 3. Production-Launch Gaps

### 🔴 Critical (blocks production launch)

| # | Gap | Location | Impact |
|---|-----|----------|--------|
| 1 | **EscalationPage is a dead shell** — `policies: never[] = []`, button does nothing, no API calls wired. | `src/frontend/src/pages/EscalationPage.tsx` | Users cannot view, create, or manage escalation policies. Entire feature is invisible. |
| 2 | **No EscalationPolicyController** — `EscalationService` and `EscalationBackgroundService` exist but there is no API controller for CRUD on policies or listing escalation events. | Missing controller | No way to create/view/delete policies or see fired escalation events from frontend. Backend runs blind. |
| 3 | **DutyHourViolation records never persisted** — `DutyHourService.CheckComplianceAsync()` creates violation objects in-memory and returns them, but they are never saved to the `DutyHourViolations` table. | `DutyHourService.cs:88-90` | Compliance check results are ephemeral — no historical tracking, no trend data, no audit trail. |
| 4 | **CalendarSyncService pushes ALL future shifts every cycle** — No tracking of which shifts were already synced. Creates duplicate Outlook events on every 5-minute tick. | `CalendarSyncService.cs:43-51` | Users get spammed with duplicate calendar events; Outlook calendar becomes unusable. |
| 5 | **PHI column encryption not implemented** — HIPAA design doc specifies column-level encryption for phones, emails, schedule assignments, swap requests. No EF Core value converters or Always Encrypted exist. | All models + `AppDbContext.cs` | HIPAA non-compliance risk. PHI stored in plaintext in Azure SQL. |
| 6 | **Session timeout not enforced** — `HipaaAuditMiddleware` references `SessionTimeoutMinutes` config but no middleware actually logs users out after inactivity. | `HipaaAuditMiddleware.cs` + `Program.cs` | HIPAA non-compliance. Sessions remain active indefinitely. |
| 7 | **No Email notification service** — Settings toggles email notifications on/off but no SMTP/email service is registered or implemented. | Missing service | Email notification toggle in settings is non-functional. |
| 8 | **No SMS notification provider** — Settings toggle for SMS escalations exists, but no SMS provider (Twilio, etc.) is configured. | Missing provider | SMS escalation toggle is non-functional. |

## 5. Auth / RBAC Model

```
Policies (Program.cs):
  RequireAdmin     → "OnCall.Admin" role
  RequireScheduler → "OnCall.Scheduler" OR "OnCall.Admin"
  RequireViewer    → "OnCall.Viewer" OR "OnCall.Scheduler" OR "OnCall.Admin"

Token Validation:
  - Multi-tenant: accepts any Azure AD tenant issuer
  - Rejects "common" tenant endpoint
  - Validates signature + audience via MS Identity Web

Frontend Auth:
  - MSAL.js popup login
  - Stores token in sessionStorage (not httpOnly cookie)
  - DEV_AUTH=true env var bypasses MSAL entirely
  - Silent token refresh → popup fallback
```
